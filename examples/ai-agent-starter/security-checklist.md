# Security checklist（最小）

このチェックリストは、AIレビューの見落としを前提に「人間が必ず確認する項目」を残すためのものです。

## 入力・外部データ

- [ ] ユーザー入力が、SQL/コマンド/テンプレート等に直接入らない（パラメータ化・エスケープ）
- [ ] 入力バリデーション/許可リストが必要な箇所を特定できている

## 認証・認可

- [ ] 認証（ログイン必須）の前提が崩れていない
- [ ] 認可（権限チェック）が必要なエンドポイント/操作が漏れていない

## 機密情報

- [ ] シークレット/トークン/パスワードをログ・例外・レスポンスに出していない
- [ ] 既存のSecret管理（GitHub Secrets、Vault等）に沿っている

## 依存関係・実行環境

- [ ] 依存関係の更新がある場合、変更理由とリスクが書かれている
- [ ] 破壊的変更がある場合、ロールバック手順がある
